# Third-party components

- `host/vendor/serial/`: pyserial 3.5, Chris Liechti and contributors, BSD license. Original metadata and LICENSE are retained in `host/vendor/pyserial-3.5.dist-info`. Downloaded from the PyPI release and checked against its SHA256. Source: https://pypi.org/project/pyserial/3.5/ and https://github.com/pyserial/pyserial/tree/v3.5 .
- ARM static executable: compiled from this project's C sources and linked with glibc 2.19 / libpthread and libgcc from the user's original `gcc-linaro-4.9.4-2017.01-x86_64_arm-linux-gnueabihf` package. Those libraries retain their respective GNU licenses (glibc LGPL-2.1-or-later; libgcc GPL with GCC Runtime Library Exception). The project source, compiler/link commands, and relinkable application objects under `release/relink/` are provided so the application can be rebuilt/relinked with a modified compatible library. Do not apply the project's MIT label to these runtime libraries.
- Matching toolchain archive and upstream source release: https://releases.linaro.org/components/toolchain/binaries/4.9-2017.01/ . glibc upstream source: https://ftp.gnu.org/gnu/glibc/glibc-2.19.tar.xz . GCC upstream source: https://ftp.gnu.org/gnu/gcc/gcc-4.9.4/ . For matching Linaro changes use the source material corresponding to the Linaro toolchain release, not an assumed unrelated revision.
- License texts are included under `licenses/` for the static runtime and driver licensing. Rebuilding with a different libc/toolchain changes the runtime provenance and should update this file.
- Zig 0.13.0 supplies Clang 18.1.6 and LLD 18.1.6 during the Windows build. The compiler package itself is not included in the delivery; the linked runtime comes from the supplied Linaro sysroot. Toolchain download: https://ziglang.org/download/0.13.0/release-notes.html .
- The board guide, NXP/ALIENTEK BSP, MfgTool and system images remain in the user's original E: drive materials. They have not been re-licensed or repackaged into this project. `docs/07_本机资料索引.md` records where they were read.
